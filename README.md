# mathStat · 数理统计互动演示

用于课堂演示和课后探索的概率统计交互页面。

[打开互动演示索引](https://yannemiya.github.io/mathStat/)

## 网页目录

- `index.html`：互动演示索引。
- `ecdf.html`：[经验分布函数与总体分布函数](https://yannemiya.github.io/mathStat/ecdf.html)。
- `clt.html`：[大样本正态近似](https://yannemiya.github.io/mathStat/clt.html)。

## 经验分布函数与总体分布函数

从索引页点击对应链接，或直接用浏览器打开 `ecdf.html`，无需安装依赖或联网。

- 选择标准正态分布 `N(0,1)` 或均匀分布 `U[-1,1]`。
- 输入样本量（1–10000），点击“生成随机样本”。
- 比较蓝色总体分布函数与红色经验分布函数，查看指定位置的样本比例、理论概率和最大偏差。
- 支持鼠标、触摸和键盘方向键操作。

## 大样本正态近似

- 左图显示总体 X 的理论密度，支持指数分布 `Exp(1)`、均匀分布 `U[-1,1]` 和正态分布 `N(0,1)`。
- 右图显示统计量的直方图、红色经验密度实线和蓝色标准正态虚线。
- 切换 `U_n = (X̄−μ)/(σ/√n)` 与 `T_n = (X̄−μ)/(S/√n)` 时沿用同一批样本。
- 用滑块或数字输入调节每组样本量 n（2–1000）与重复抽样次数 B（100–10000）。
- 页面可离线打开，不依赖外部脚本或网络服务。

`ecdf.html` 对应备课工作文件 `../interact/经验分布函数.html`，
`clt.html` 对应 `../interact/大样本近似.html`。网页版另有返回索引的导航；
修改演示后，应同步更新对应的本地版和网页版正文与脚本，再检查并发布。
演示页不标注课件章节号。新增演示时在 `index.html` 的列表中添加链接。
不要把教材、点名册或其他备课资料加入此仓库。

# mathStat · 数理统计互动演示

用于课堂演示和课后探索的概率统计交互页面。

## 经验分布函数与总体分布函数

直接用浏览器打开 `index.html`，无需安装依赖或联网。

- 选择标准正态分布 `N(0,1)` 或均匀分布 `U[-1,1]`。
- 输入样本量（1–10000），点击“生成随机样本”。
- 比较蓝色总体分布函数与红色经验分布函数，查看指定位置的样本比例、理论概率和最大偏差。
- 支持鼠标、触摸和键盘方向键操作。

## GitHub Pages

仓库中只有可公开的静态网页及说明，不需要构建步骤。发布时在仓库的
`Settings → Pages` 中选择 `Deploy from a branch`，分支为 `main`，目录为 `/(root)`。
启用后，仓库首页的 `index.html` 即为网站首页。

## 维护

本仓库位于课程备课目录的 `mathStat/` 子目录，是独立的发布仓库。
当前 `index.html` 与备课工作文件 `../interact/经验分布函数.html` 内容一致；
修改该演示后，应同步更新这两份文件，再检查并发布。
不要把教材、点名册或其他备课资料加入此仓库。

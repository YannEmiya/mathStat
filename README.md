# mathStat · 数理统计互动演示

用于课堂演示和课后探索的概率统计交互页面。

[打开互动演示索引](https://yannemiya.github.io/mathStat/)

## 网页目录

- `index.html`：互动演示索引。
- `ecdf.html`：[经验分布函数与总体分布函数](https://yannemiya.github.io/mathStat/ecdf.html)。

## 经验分布函数与总体分布函数

从索引页点击对应链接，或直接用浏览器打开 `ecdf.html`，无需安装依赖或联网。

- 选择标准正态分布 `N(0,1)` 或均匀分布 `U[-1,1]`。
- 输入样本量（1–10000），点击“生成随机样本”。
- 比较蓝色总体分布函数与红色经验分布函数，查看指定位置的样本比例、理论概率和最大偏差。
- 支持鼠标、触摸和键盘方向键操作。
